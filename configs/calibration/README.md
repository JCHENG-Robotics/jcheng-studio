# Hand-eye calibration

`calibration_table_down_20261118.json` is the table-down TSAI hand-eye result
used by `configs/takeover.yaml` (`task.hand_eye`). It was measured on the
ArmPi Ultra on 2026-11-18 and is copied from the frozen
`jcheng-manipulation` baseline:

<https://github.com/JerichoCheng/jcheng-manipulation/blob/main/evidence/calibration/20261118/table_down/calibration_table_down_20261118.json>

It is a project measurement, not vendor code. The console reads it only for
task planning and the visual workbench. A new calibration is a new file with
its own date and version; do not edit this file in place. The live camera
extrinsic is exposed through the gateway `/tf` path, not inferred from this
file.
